## Recurring skills

### The strongest pattern is:
* Modern C++ — C++17/20+, RAII, templates, modern language features.
* Linux/Unix — clearly important for systems roles.
* Concurrency — threads, synchronization, multithreading.
* Networking — especially TCP/IP, messaging and networked systems.
* Testing + debugging — automated tests, debugging production problems.
* Build/tooling — CMake, compilers/toolchains, CI/CD, Git.
* Performance — profiling, latency, memory efficiency.
* Distributed systems — increasingly appears in backend/platform/system roles.
* Software architecture — designing components rather than just implementing tickets.

Interestingly, broader European data supports the same picture: Linux, networking and Python are among the most common systems-engineering requirements, while C++ roles frequently pair C++ with Linux, Kubernetes, Python and observability.
